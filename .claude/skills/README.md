# Skills di progetto

Skill agentiche (formato [agent skills](https://agentskills.io/home)) caricate
automaticamente da Claude Code e altri agenti compatibili.

## Origine

Sottoinsieme curato di [Android skills](https://developer.android.com/tools/agents/android-skills)
(Google LLC, Apache 2.0 — vedi `LICENSE.txt`), selezionato per questo progetto:

| Skill | Quando serve |
|---|---|
| `testing-setup` | Strategia e infrastruttura test (unit, UI, screenshot) |
| `styles` | Theming e stili Jetpack Compose (Material3) |
| `edge-to-edge` | Adeguamento edge-to-edge per target Android recenti |
| `android-cli` | Uso della Android CLI per task agentici |

## Aggiornamento

Sorgente: https://github.com/google/android-skills — ricopiare la cartella
della skill aggiornata preservando `SKILL.md` e `references/`.
